# 법률 근거 관리 원칙

## 목적

자동 분석 규칙이 모델의 추측이나 일반적인 상식이 아니라 확인 가능한
대한민국 법령에 연결되도록 관리합니다.

## 허용 근거

초기 버전에서 규칙의 직접 근거로 사용할 수 있는 자료는 다음과 같습니다.

1. 국가법령정보센터의 현행 법령과 조문
2. 개인정보보호위원회가 공개한 고시, 지침, 안내서
3. 국가법령정보센터에 공개된 판례, 법령해석례 및 행정심판례

블로그, 언론 기사, 법률사무소 홍보 글과 생성형 AI의 답변은 규칙의 직접
근거로 사용할 수 없습니다. 이 자료들은 조사 단서로만 사용할 수 있습니다.

## 규칙 등록 요건

새 규칙에는 최소한 다음 값이 있어야 합니다.

- 고유한 규칙 ID
- 법령 또는 공식 문서명
- 조문 번호나 공식 문서 식별자
- 적용 문서 유형
- 사용자에게 표시할 검토 문구
- 공식 원문 URL
- 기준 법령 시행일
- 근거 확인일

## 결과 표현 원칙

- `위법`, `불법`, `무효`처럼 법적 결론을 자동 확정하지 않습니다.
- `문구 확인`, `누락 가능성`, `검토 필요`로 결과를 제한합니다.
- 문구가 있더라도 구체성, 사실관계, 다른 법률의 특례까지 충족한다고 보지 않습니다.
- 근거가 충돌하거나 적용 범위가 불명확하면 전문가 검토가 필요하다고 표시합니다.

## 법률 변경 절차

1. 국가법령정보센터에서 현재 시행 중인 조문과 시행일을 확인합니다.
2. 개정 전후 조문과 부칙의 시행일을 비교합니다.
3. 테스트 문서를 추가하거나 기존 기대 결과를 수정합니다.
4. `data/legal_sources.json`의 확인일과 근거 URL을 갱신합니다.
5. 전체 테스트를 통과한 후 배포합니다.

공포되었지만 아직 시행되지 않은 조문은 현재 규칙과 섞지 않고 별도 예정
버전으로 관리해야 합니다.
